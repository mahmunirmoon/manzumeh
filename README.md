# منظومهٔ شمسی — آزمایشگاه تعاملی مدارها

وب‌اپلیکیشن آموزشی تعاملی منظومهٔ شمسی با React + Vite + Tailwind CSS v4.
خورشید و هر هشت سیاره با دوره‌های مداری نسبیِ واقعی در حرکت‌اند؛ روی هر جرم کلیک کنید تا نام، قطر، فاصله از خورشید، دورهٔ مداری، سرعت مداری و یک دانستنی را ببینید. کنترل‌های پخش/مکث، سرعت (۰٫۵ تا ۷۳۰ روز بر ثانیه) و نمایش مدارها/برچسب‌ها/دنباله‌ها نیز موجود است.

طراحی توسط **امیرعلی** — از شاگردان خانم دکتر آقایی ✨

---

## اجرای محلی (حالت توسعه)

```bash
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:3000` باز کنید.

## ساخت نسخهٔ نهایی

```bash
npm run build
```

خروجی در پوشهٔ `dist/` ساخته می‌شود — همین پوشه چیزی است که روی هاست آپلود می‌کنید.

## انتشار روی هاست و دامنهٔ شخصی

۱. بعد از خرید هاست و دامنه، ابتدا `npm run build` را اجرا کنید.
۲. **محتویات** پوشهٔ `dist/` (نه خود پوشه را) در `public_html` هاست خود آپلود کنید.
۳. تمام شد! چون آدرس فایل‌های JS و CSS و favicon به‌صورت نسبی (relative) بیلد می‌شوند، سایت هم روی روت دامنه (`example.com/`) و هم داخل هر زیرپوشه‌ای (`example.com/solar/`) درست کار می‌کند و نیازی به تنظیم اضافی نیست.

سازگار با: هاست‌های cPanel، Netlify، Vercel، Cloudflare Pages و هر وب‌سرور استاتیک دیگر.

> نکته: فونت‌ها (Lalezar و Vazirmatn) از Google Fonts بارگذاری می‌شوند، پس بازدیدکننده به اینترنت نیاز دارد.

## انتشار خودکار روی GitHub Pages

فایل `.github/workflows/deploy.yml` داخل همین بسته قرار دارد:

۱. پروژه را در یک ریپازیتوری GitHub با نام `manzumeh` پوش کنید.
۲. در `Settings → Pages` گزینهٔ **Source** را روی **GitHub Actions** بگذارید.
۳. با هر push به شاخهٔ `main`، سایت به‌طور خودکار بیلد و منتشر می‌شود:
   `https://نام‌کاربری.github.io/manzumeh/`

## ساختار پروژه

```
index.html                  صفحهٔ اصلی + اتصال فونت‌ها و favicon
public/favicon.svg          آیکون سایت (بنفش نئونی با سیارهٔ حلقه‌دار)
src/App.tsx                 چیدمان اصلی، هدر و کنترل‌ها
src/components/             بوم شبیه‌سازی، پنل اطلاعات، داک کنترل و…
src/data/bodies.ts          داده‌های واقعی خورشید و هشت سیاره
src/lib/                    فرمت اعداد فارسی و بسته‌بندی ZIP
.github/workflows/deploy.yml دیپلوی خودکار GitHub Pages
```

## دریافت فایل‌ها از داخل خود سایت

در هدر وب‌اپ دو دکمهٔ دانلود وجود دارد:

- **«نسخهٔ هاست»** — فایل `manzumeh-host.zip` را دانلود می‌کند: خروجیِ **نهایی و آمادهٔ آپلود** (همان چیزی که الان در مرورگر می‌بینید). محتویش را مستقیم در `public_html` هاست جدید بریزید؛ بدون نیاز به npm یا بیلد، روی روت دامنه و هر زیرپوشه‌ای کار می‌کند.
- **«سورس پروژه»** — فایل `manzumeh-source.zip`: کدِ منبع کامل برای GitHub یا توسعهٔ محلی (`npm install` و `npm run dev`).

> ⚠️ فایل‌های «سورس» با دابل‌کلیک روی `index.html` باز **نمی‌شوند** (صفحه سیاه می‌ماند)؛ چون برای اجرا به سرور توسعهٔ Vite نیاز دارند. برای آپلود روی هاست همیشه از «نسخهٔ هاست» استفاده کنید.
