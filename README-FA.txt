فایل‌های آماده برای پروژه mahmunirmoon/manzumeh

این بسته بدون دست‌زدن به App.tsx پیچیده‌ی پروژه، Help را به‌صورت یک پنجره/صفحه‌ی تمام‌صفحه اضافه می‌کند
و یک لایه‌ی بسیار محافظه‌کارانه برای موبایل نیز فعال می‌کند.

مسیر فایل‌ها در GitHub:

1) src/components/HelpWidget.tsx
   فایل جدید — داخل src/components ایجاد/آپلود شود.

2) src/mobile-fixes.css
   فایل جدید — مستقیم داخل پوشه src قرار بگیرد.

3) src/main.tsx
   فایل موجود — با نسخه‌ی داخل این بسته جایگزین شود.

بعد Commit changes را بزنید.
GitHub Actions باید build و deploy را اجرا کند.

آنچه Help توضیح می‌دهد:
- برنامه چه کاری انجام می‌دهد
- روش استفاده
- اطلاعاتی که نمایش می‌دهد
- منابع/دقت داده‌ها
- توضیح اینکه نمایش منظومه مقیاس واقعی نیست

بررسی موبایل:
کد فعلی پروژه از قبل طراحی موبایلی مناسبی دارد:
- زیر 768px صفحه عمودی و اسکرول‌شونده است
- بوم شبیه‌سازی ارتفاع جداگانه دارد
- کارت اطلاعات سیاره در موبایل در جریان عادی صفحه قرار می‌گیرد
- انتخابگر سیاره‌ها برای لمس مناسب است
- footer از safe-area-inset-bottom استفاده می‌کند

mobile-fixes.css فقط محافظت‌های کوچک اضافه می‌کند:
- جلوگیری از overflow افقی
- touch target بهتر
- safe area
- رفتار بهتر در گوشی‌های کوتاه/landscape
- اسکرول مطمئن Help
